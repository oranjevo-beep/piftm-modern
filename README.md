# ТМ «ПІФ» — Каталог та прайс-лист побутової і професійної хімії

Офіційний вебкаталог і прайс-лист продукції **ТМ «ПІФ» (ТОВ «Кодимський Райпостач», м. Одеса, пров. Вознесенський № 3, з 2005 року)**.

## Структура проєкту

- `index.html` — головна сторінка каталогу, прайс-лист із розрахунком упаковок, калькулятор економії HoReCa (тара 5 л), кошик замовлення (WhatsApp / E-mail) та прихований редактор цін.
- `products.json` — актуальні ціни з ПДВ, фасування, штрих-коди та кількість штук в упаковці.
- `images/` — фото продукції та логотип ТМ «ПІФ».
- `site.webmanifest` — метадані вебдодатка.

## Керування цінами (для адміністратора)

Прихований редактор цін відкривається:
- **5 швидкими кліками** по логотипу **ТМ «ПІФ»** у шапці сайту,
- комбінацією клавіш **`Ctrl + Shift + E`**,
- або додаванням **`#admin`** чи **`?admin=1`** до адреси сторінки.

У редакторі можна змінити ціни вручну або проіндексувати їх (`-5%`, `+5%`, `+10%`), завантажити готовий `products.json` або опублікувати зміни напряму у GitHub за допомогою Fine-Grained Personal Access Token.
